================================================================================
ANDROID RELEASE SIGNING - GITHUB SECRETS SETUP INSTRUCTIONS
================================================================================

CRITICAL: The Android release keystore and passwords have been removed from 
the repository for security. You MUST configure GitHub Secrets before the 
build workflow can succeed.

================================================================================
REQUIRED GITHUB SECRETS
================================================================================

Navigate to: Repository Settings > Secrets and variables > Actions > New secret

Add the following 4 secrets:

1. RELEASE_KEYSTORE_BASE64
   - The base64-encoded keystore file
   - To generate from your existing keystore:
     
     base64 -i android/app/flowpos-release.keystore | tr -d '\n' > keystore_base64.txt
     
   - Copy the entire content of keystore_base64.txt (single line, no newlines)
   - Paste as the secret value
   - Delete keystore_base64.txt after copying (never commit it)

2. RELEASE_KEYSTORE_PASSWORD
   - The keystore password (previously: flowpos123)
   - Enter the password as plain text

3. RELEASE_KEY_ALIAS
   - The key alias (previously: flowpos)
   - Enter the alias as plain text

4. RELEASE_KEY_PASSWORD
   - The key password (previously: flowpos123)
   - Enter the password as plain text

================================================================================
VERIFICATION
================================================================================

After configuring all 4 secrets:
1. Trigger the "Build FlowPOS Pro APK" workflow
2. The workflow will decode the keystore from the secret
3. The APK will be signed with your release key
4. Verify the workflow completes successfully

================================================================================
SECURITY NOTES
================================================================================

- The keystore file is now stored ONLY in GitHub Secrets (encrypted at rest)
- Passwords are never exposed in workflow files or logs
- The keystore is decoded to a temporary directory (RUNNER_TEMP) that is 
  automatically cleaned up after the job completes
- Repository readers can no longer access signing credentials
- Only users with repository admin/write access can view/modify secrets

================================================================================
MAINTAINING SIGNING CONTINUITY
================================================================================

IMPORTANT: Use the SAME keystore that was previously committed to ensure 
new APK releases can update existing installations. If you generate a new 
keystore, users will need to uninstall and reinstall the app (losing data).

The previously committed keystore should still be in your local clone at:
  android/app/flowpos-release.keystore

If you've lost the keystore, check:
1. Local git history: git log --all --full-history -- android/app/flowpos-release.keystore
2. Previous CI build artifacts or releases
3. Developer workstations
