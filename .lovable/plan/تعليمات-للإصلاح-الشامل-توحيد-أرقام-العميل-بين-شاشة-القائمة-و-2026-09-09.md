### 1. تنفيذ استعلام تصحيح البيانات القديمة (SQL Migration)

يرجى توفير سكريبت الهجرة (Migration) لتنفيذ التالي لمرة واحدة:

```sql

-- أولاً: ربط الفواتير السابقة بالعملاء عن طريق مطابقة الاسم (إذا كان customer_id فارغاً)

UPDATE invoices i

JOIN customers c ON i.customer_name = [c.name](http://c.name)

SET i.customer_id = [c.id](http://c.id)

WHERE i.customer_id IS NULL;

-- ثانياً: إعادة احتساب إحصائيات العملاء بناءً على الفواتير النشطة فقط

UPDATE customers c

SET 

    invoice_count = (

        SELECT COUNT(id) FROM invoices 

        WHERE customer_id = [c.id](http://c.id) AND status NOT IN ('refunded', 'cancelled')

    ),

    total_purchases = (

        SELECT COALESCE(SUM(total), 0) FROM invoices 

        WHERE customer_id = [c.id](http://c.id) AND status NOT IN ('refunded', 'cancelled')

    ),

    total_debt = (

        SELECT COALESCE(SUM(remaining_amount), 0) FROM invoices 

        WHERE customer_id = [c.id](http://c.id) AND payment_type = 'postponed' AND status NOT IN ('refunded', 'cancelled')

    );

```

### 2. إنشاء دالة الحساب الموحدة (customer-stats.ts)

يرجى إنشاء وتضمين الملف التالي بالمنطق التالي:

```typescript

// src/lib/cloud/customer-stats.ts

export interface CustomerStats {

  invoiceCount: number;

  totalPurchases: number;

  totalDebt: number;

}

export function buildCustomersStatsMap(

  activeInvoices: any[], // يرجى استبدال any بنوع الفاتورة الخاص بالتطبيق Invoice Type

): Map<number | string, CustomerStats> {

  const statsMap = new Map<number | string, CustomerStats>();

  activeInvoices.forEach((invoice) => {

    if (invoice.status === 'refunded' || invoice.status === 'cancelled') return;

    const identifier = invoice.customer_id || invoice.customer_name;

    if (!identifier) return;

    const currentStats = statsMap.get(identifier) || {

      invoiceCount: 0,

      totalPurchases: 0,

      totalDebt: 0,

    };

    currentStats.invoiceCount += 1;

    currentStats.totalPurchases += [invoice.total](http://invoice.total) || 0;

    

    if (invoice.payment_type === 'postponed') {

      currentStats.totalDebt += invoice.remaining_amount || 0;

    }

    statsMap.set(identifier, currentStats);

  });

  return statsMap;

}

```
