## 3. الحجم الافتراضي عند أول تشغيل
- الترتيب الحالي: 60 / 70 / 80 ... المطلوب "الثالث من الصغيرة" = **80% (11.2px)**.
- `src/lib/ui-scale-config.ts`: `DEFAULT_UI_SCALE_ID = '80'`, `DEFAULT_UI_SCALE_PX = '11.2px'`.
- `index.html` سطر 34-36: `defaultScale = '80'` و fallback `'11.2px'`.
- `src/index.css` (~1889): fallback root font-size = 11.2px.
- يطبق فقط عند عدم وجود قيمة محفوظة، فلا يتأثر المستخدمون الحاليون.

## 4. المشتريات
أ) أزرار "إضافة فاتورة شراء" و"شراء سريع" في `src/pages/Purchases.tsx`: `grid grid-cols-2 gap-2`، كل زر `min-w-0 h-11 whitespace-normal leading-tight text-center`، بدون `overflow-x-auto`.
ب) نافذة `QuickPurchaseDialog.tsx` ونافذة `PurchaseInvoiceViewDialog.tsx`: الحاوية `w-[min(100vw-1rem,42rem)] max-h-[calc(100dvh-2rem)] flex flex-col`، رأس وتذييل ثابتان، المحتوى `flex-1 overflow-y-auto`، الجداول تتحول إلى بطاقات عمودية تحت `sm`، كسر الكلمات `break-words`.
ج) تعديل فاتورة شراء دون إخلال بالحسابات:
- زر "تعديل" في نافذة التفاصيل (للمالك/الأدمن فقط).
- لا يُعدَّل السجل الأصلي: دالة خادم ذرية `edit_purchase_invoice_atomic(invoice_id, new_lines, op_id)` تقوم داخل معاملة واحدة بـ: قفل المنتجات `FOR UPDATE`، عكس حركة المخزون والذمة/الصندوق للأسطر القديمة، تسجيل الأسطر الجديدة كحركات جديدة، إعادة حساب متوسط التكلفة، وتعليم الفاتورة القديمة `status='superseded'` مع `replaced_by`، وسجل تدقيق (المستخدم، السبب، قبل/بعد)، ومفتاح `op_id` فريد لمنع التكرار.
- يرفض التعديل إذا كانت الكمية المباعة من الصنف تجعل المخزون سالباً.
- يُكتب SQL الدالة بعد قراءة جداول المشتريات الحالية (`purchase_invoices`, `purchase_history` والحقول الفعلية) — خطوة تحقق أولى.

## 5. كشف الديون والعملة
- مراجعة `src/pages/Debts.tsx` و`DebtsReport.tsx`: كل مبلغ يمر عبر دالة واحدة `formatInCurrency(usdAmount, currency, rate)` من `use-currency` (تحويل القيمة + الرمز معاً)، مع سطر صغير "= X $" عند اختيار عملة غير الدولار ليتضح أن القيمة محوّلة.
- كشف الحساب: كل فاتورة دين قابلة للتوسيع (Accordion) تعرض الأصناف والكمية والسعر والمدفوع والمتبقي.
