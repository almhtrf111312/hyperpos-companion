# تجربة نشر التحديث إلى قناة Telegram

## الهدف
نرسل نسخة التطبيق الحالية إلى فرع المستخدمين `public-release`، ونتأكد أن البوت نشر رسالة التحديث في القناة.

## الخطوات
1. أتأكد أن آخر إصدار (v1.4.0 / Build 353) مرفوع إلى `main`، وأن التطبيق يُبنى بلا أخطاء.
2. أراجع ملف التشغيل التلقائي في GitHub (`.github/workflows/telegram-public-release.yml`):
   - يستخدم `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID`.
   - يعمل عند كل رفع إلى `public-release`.
   - أصلح فيه أي خطأ يمنع الإرسال.
3. أرفع الإصدار بالكامل للمستخدمين. لا أستطيع تنفيذ أوامر git بنفسي، فالرفع له طريقتان:
   - **عبر GitHub (الأسهل):** تفتح طلب دمج من `main` إلى `public-release` ثم تضغط "Merge". وإذا لم يكن الفرع موجوداً، تنشئه من `main` فيعمل التشغيل التلقائي فوراً.
   - **أو** أضيف زر تشغيل يدوي "Run workflow" إلى ملف التشغيل التلقائي، فتضغطه من تبويب Actions.
4. التحقق: نفتح تبويب Actions في GitHub ونرى هل نجح التشغيل، ثم نتأكد أن الرسالة وزر التحميل ظهرا في القناة. إذا فشل التشغيل، أقرأ رسالة الخطأ وأصلح السبب. أكثر الأسباب احتمالاً:
   - رقم القناة لا يبدأ بـ `-100`.
   - البوت ليس مشرفاً في القناة.

## ملاحظة مهمة
يجب أن يكون `TELEGRAM_CHAT_ID` هو رقم القناة الذي يبدأ بـ `-100`، أو `@اسم_القناة`. أما الرقم `74656690` فهو رقم حسابك الشخصي، فإذا وضعته ستصل الرسالة إليك أنت فقط.
