# خطة: تحسين توجيه الذكاء الاصطناعي للمشروع (Skills + ملفات تعليمات)

## الهدف
تسريع تنفيذ المهام وتقليل التكرار والأخطاء عبر تعليمات دائمة يقرأها الذكاء الاصطناعي تلقائيًا في كل جلسة — بدون الحاجة لإعادة شرح قواعد المشروع كل مرة.

## ما هو موجود حاليًا (تم التحقق منه)
- `AGENTS.md` موجود في جذر المشروع ويحتوي قواعد عامة + قسم "Frozen features" (المستودعات).
- ذاكرة مشروع دائمة تحفظ ~60 قاعدة (أرقام غربية، ExcelJS، صيغة الأرباح، تجميد المستودعات، إلخ) وتُحمَّل تلقائيًا كل جلسة.
- لا توجد Skills مفعّلة حاليًا في مساحة العمل.

## الأدوات الثلاث المتاحة

### 1. ذاكرة المشروع (الأقوى — تعمل تلقائيًا)
قواعد دائمة تُطبَّق على كل رسالة بدون أي إعداد منك. معظم قواعدك محفوظة فيها أصلًا. أي قاعدة جديدة تذكرها لي تُحفظ فورًا.

### 2. ملف `AGENTS.md` (للقرارات التقنية)
يُقرأ في كل جلسة. مناسب لقواعد مثل: "لا تلمس ملفات المستودعات"، "استخدم ExcelJS"، "ارفع رقم الإصدار مع كل تعديل".

### 3. Skills (مهارات جاهزة)
ملفات تعليمات متخصصة (مثل: مهارة فحص أمني، مهارة تدقيق حسابات، مهارة كتابة تقارير). طريقتان لإضافتها:
- **أنت تضيفها:** من الإعدادات > Skills، أو تكتب `/` في مربع المحادثة.
- **أنا أكتبها لك:** تطلب مني مهارة معينة (مثل "مهارة فحص المزامنة") فأكتبها كمسودة وتحتاج تفعيلها من الإعدادات.

## خطة العمل المقترحة

1. **تحديث `AGENTS.md`** بقواعد موجزة مجرّبة:
   - قائمة الملفات المجمّدة (المستودعات وتحويل العهدة) — موجودة، سنبقيها.
   - قاعدة رفع الإصدار + تحديث changelog مع كل تعديل.
   - قاعدة: استخدام الأدوات الجاهزة (قراءة/تعديل مباشر) بدل أوامر معقدة.
   - قاعدة: فحص الأخطاء بعد كل تعديل قبل إعلان الانتهاء.

2. **تعزيز ذاكرة المشروع** بأي قواعد تنقصها (تُحفظ أثناء العمل، لا تحتاج خطوة منفصلة).

3. **اقتراح Skills مفيدة لهذا المشروع** (اختياري — تفعّل ما يعجبك):
   - مهارة "تدقيق مالي": تفحص ترابط الفواتير/الديون/العملاء قبل أي تعديل مالي.
   - مهارة "فحص المزامنة": تتبع مسار البيع أوفلاين → قائمة المزامنة → السحابة.
   - مهارة "مراجعة أمنية": تفحص صلاحيات الجداول والدوال قبل النشر.

4. **إذا كان لديك Skills أو ملفات تعليمات من موقع آخر:** أرسلها لي هنا (الصق النص أو ارفع الملف) وسأحفظها كمسودات لتفعّلها من الإعدادات.

## ملاحظة مهمة
هذه الأدوات توجّه الذكاء الاصطناعي بشكل أفضل وتقلل إعادة الشرح، لكنها لا تغيّر طريقة احتساب الاستهلاك — الفائدة الحقيقية هي تنفيذ أدق وأسرع بمحاولات أقل.

## التقني (للمرجع)
- تعديل `AGENTS.md` فقط + حفظ قواعد في الذاكرة.
- المسودات تُكتب تحت `.agents/skills/<name>/` وتُفعَّل عبر أداة apply بعد موافقتك.
- لا تعديل على كود التطبيق نفسه في هذه الخطة.
