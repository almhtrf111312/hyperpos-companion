# إضافة حزمة المرجع المالي كـ Skill للمشروع

## الهدف
حفظ حزمة «Flow POS Financial Core» التي أرفقها المستخدم كمسودة Skill داخل المشروع، بحيث تُحمَّل تلقائيًا عند أي مهمة مالية (مبيعات، مرتجعات، مخزون، ديون، صندوق، شركاء، تقارير، مزامنة، هجرات) — دون استهلاك وقت في إعادة شرح القواعد كل مرة.

## ما سيتم إنشاؤه

```text
.agents/skills/flow-pos-financial-core/
├── SKILL.md                        # الدستور المالي والموجّه (معدّل)
└── references/
    ├── sales-and-debts.md          # المبيعات والخصومات والضرائب والديون
    ├── refunds-and-reversals.md    # المرتجعات والحركات العكسية
    ├── inventory-and-purchases.md  # المخزون والمشتريات ومتوسط التكلفة
    ├── cashbox-and-shifts.md       # الصندوق والورديات
    ├── partners-expenses-reports.md# الشركاء والمصاريف والتقارير
    ├── security-audit-and-sync.md  # الأمان والتدقيق والمزامنة دون اتصال
    └── migrations-and-verification.md # الهجرات والتحقق (معدّل)
```

## التعديلات على المحتوى المرفوع

1. **استثناء الاختبارات (بطلب المستخدم):**
   - حذف قسم «متطلبات الاختبار» بالكامل من التعليمات.
   - في `migrations-and-verification.md`: إزالة قسم «Minimum proof for a financial mutation» (قائمة الاختبارات العشرة) والإبقاء على تسلسل الهجرات الآمنة وفحوصات الاتساق (Conservation checks) لأنها قواعد تحقق منطقية وليست اختبارات تستهلك وقتًا.
2. **الإبقاء على كل القواعد المالية الأخرى كما هي** دون تغيير مضمونها:
   - الضريبة ليست ربحًا، الخادم هو مصدر الحقيقة، ممنوع الحذف المالي، الذرّية، Idempotency، التقريب المركزي، التدقيق، الصلاحيات من الخادم، أرباح الآجل المعلقة، طابور المزامنة الدائم.
3. **مواءمة مع قواعد المشروع الموجودة:** الحزمة متوافقة مع قواعدنا الحالية (الأرقام الغربية، Math.round، الاسترداد الذرّي، طابور المزامنة) — لا يوجد تعارض.

## خطوات التنفيذ

1. إنشاء مجلد `.agents/skills/flow-pos-financial-core/` مع `SKILL.md` (بعد حذف قسم الاختبارات).
2. نسخ الملفات السبعة إلى `references/` مع تعديل ملف الهجرات فقط.
3. تفعيل المسودة عبر أداة تطبيق الـ Skill لتصبح متاحة للاستخدام.
4. تحديث `version.json` و`public/changelog.json` (إصدار جديد) حسب قاعدة المشروع.

- بعد التفعيل، أي تعديل مالي مستقبلي سيتبع هذه القواعد تلقائيًا.
