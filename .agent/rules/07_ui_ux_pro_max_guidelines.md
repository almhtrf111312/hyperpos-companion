# 07 — UI/UX Pro Max Engine (Design Rules & Standby Protocol)

## 🎯 Purpose
This document governs the standards for all visual design, layout refactors, and aesthetic enhancements in FlowPOS Pro under the **UI/UX Pro Max** framework.

---

## ⏸️ Standby Activation Protocol
* **Default Mode: STANDBY (`وقفهم على الزي`)**
  * During routine bug fixes, sync engine debugging, or financial calculations, this system remains dormant to avoid unwanted visual changes.
* **Trigger Conditions:**
  * Activated when the user explicitly requests:
    * "UI/UX Pro Max"
    * "حسّن التصميم / الواجهة" (Improve design / interface)
    * "إعادة تصميم / تنسيق" (Redesign / styling)
    * Creation of new UI views, dialogs, or mobile layout optimizations.

---

## 💎 Design Invariants under UI/UX Pro Max
1. **Ergonomic Touch Targets:** Minimum 44px (desktop) / 48px (mobile/tablet).
2. **Daylight & Dark Mode Contrast:** High visual hierarchy; no washed-out text or invisible borders.
3. **Arabic RTL Perfection:** True optical alignment and monospace financial numbers.
4. **Fast Micro-Interactions:** Snappy animations capped at 200ms; tactile active compressions.
5. **No AI Slop:** Clean, purposeful industrial aesthetics; no generic gradients or decorative clutter.
6. **UCL Lock:** Established button labels, action text, and checkout flow order are immutable.
